## 왜 이 형태인가

두 개의 6 이 맞물린다. **66일**을 뜻하는 동시에 **끊기지 않고 이어진다**는 뜻이다.

V1 진단에서 나온 핵심 문제가 *"며칠 빠지면 돌아올 이유가 없다"* 였다.
숫자만 그리면 66 은 그냥 숫자다. 두 볼을 맞물리게 하면
이 서비스가 무엇을 지키려는 서비스인지가 형태에 들어간다.

버린 안 두 개도 기록해 둔다.

| | 왜 버렸나 |
|---|---|
| 숫자 66 (Anton) | 안전하지만 흔하다. 66 이 알려지기 전까지 아무 의미도 전달하지 않는다 |
| 진행판 한 칸 | 만들어보니 **앱 서랍(런처) 아이콘**으로 읽혔다. 40px 아래에서 칸이 뭉갠다 |

## 파일

| 파일 | 용도 |
|---|---|
| `logo-mark.svg` | 마크 **기본형**. 24px 초과일 때 |
| `logo-mark-small.svg` | 마크 **소형**. 24px 이하일 때 |
| `app-icon.svg` | 앱 아이콘 (여백 넓음) |
| `favicon.svg` | 파비콘 (여백 좁음 · 획 굵음) |
| `apple-touch-icon.png` | 180×180 |
| `favicon-32.png` / `favicon-16.png` | SVG 미지원 폴백 |

마크와 아이콘의 여백·획이 다른 건 실수가 아니다.
브라우저에서 실측해 보니 앱 아이콘 비율을 그대로 16px 로 줄이면 뭉갰다.

## 기하

두 벌이다. 하나로 모든 크기를 감당하지 않는다.

| | 획 | 볼 반지름 | 볼 중심 간격 |
|---|---:|---:|---:|
| 기본형 | 17 | 27 | 68 |
| 소형 | 22 | 26 | 74 |

중심 간격은 `2r + 획` 일 때 두 볼의 바깥선이 정확히 맞닿는다.
기본형은 여기서 3 을 좁혀 **살짝 겹치게** 했다 — 맞물린 것으로 읽히게.

## 사용 규정

**클리어스페이스** — 볼의 지름을 `x` 로 잡고 사방에 `x` 를 비운다.

**최소 크기** — 마크 단독 16px (소형). 가로 락업은 마크 높이 20px.

**락업** — 마크 높이가 기준이다. 워드마크 = 마크 높이 × 0.92, 사이 간격 = × 0.42.

**색** — 네 조합만 쓴다.

| 배경 | 로고 |
|---|---|
| 크림 `#FBF8F2` | 코랄 `#F04E2C` |
| 흰색 | 잉크 `#1A1A1A` |
| 코랄 `#F04E2C` | 크림 `#FBF8F2` |
| 잉크 `#1A1A1A` | 크림 `#FBF8F2` |

**사진 위에는 올리지 않는다.** V1 의 Hero 대비 문제가 그래서 생겼다
(`v2/V1-DIAGNOSIS.md` §3.5). 코랄은 배경 대비 3.4:1 이라 원래 텍스트용이 아니다.

**하면 안 되는 것** — 가로로 늘이기 · 기울이기 · 저대비 색 · 락업 간격 임의 변경.

## 타이포그래피

제품 전체 기본값은 **Pretendard · 행간 140% · 자간 −3%** 다 (`v2/V2-SCOPE.md` 결정 7).
워드마크도 같은 값을 쓴다.

**예외 하나** — Anton(숫자)은 **행간 100%** 를 유지한다.
`D+23` 이 96px 인데 행간 140% 를 주면 줄상자가 134px 이 되어 Hero 가 무너진다.
숫자는 한 줄짜리 표시값이라 행간이 의미가 없다.

> ⚠️ **Figma 에서 Pretendard 가 안 잡힌다.**
> 브라우저판 Figma 는 로컬 폰트에 접근하지 못한다 (설치돼 있어도 목록에 안 뜬다).
> **데스크톱 앱**으로 열거나 **Figma Font Helper** 를 실행해야 한다.
> 그전까지 Figma 안의 한글은 Noto Sans KR 대체 상태이므로
> **행간·자간을 Figma 화면에서 확정하지 않는다.**

## 아직 안 한 것 — 워드마크

「육십육」 은 지금 **Noto Sans KR Bold 에 자간 −3% 만 준 상태**다.
손으로 그린 로고타입이 아니다.

다듬을 지점은 정해져 있다. **육십육에는 이응(ㅇ)이 두 개 있고, 마크에도 볼이 두 개 있다.**
이 둘을 같은 원으로 통일하면 마크와 글자가 한 몸이 된다.

다만 한글 자소를 코드로 그리면 반드시 어색해진다. **05단계에서 직접 손으로 그린다.**
그때까지는 아웃라인으로 변환해 쓴다 — 폰트에 의존하면 환경마다 달라진다.
