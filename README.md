# 육십육 (SIXTYSIX)

> 66일, 같이 시작한 사람들과 끝까지.

**[▶ 라이브 데모 — sixtysix-taupe.vercel.app](https://sixtysix-taupe.vercel.app)**

> 모바일 화면 기준으로 만들었습니다. 데스크톱에서는 브라우저 개발자도구의 기기 모드(430×932)로 보시면 의도한 화면이 나옵니다.

같은 날 시작한 30명 코호트와 함께 하나의 습관을 66일 동안 매일 인증하고 완주하는 습관 챌린지 커뮤니티 모바일 웹 MVP입니다.

V1은 HTML · CSS · JavaScript로 구현한 12개 화면의 동결된 비교 기준입니다. 현재 개발 대상은 **React · TypeScript 기반 V2**입니다.

## 무엇을 푸는 서비스인가

습관 챌린지 단톡방에 들어갔다가 조용히 나온 경험에서 출발했습니다.

| 문제 | 육십육의 답 |
|---|---|
| 인증이 채팅에 묻혀 내가 어디까지 왔는지 안 보인다 | 홈과 기록에 항상 떠 있는 **66칸 진행판** |
| 며칠 빠지면 복귀할 명분이 없어 이탈한다 | 내보내지 않는 **휴면 상태**와 인증 한 번이면 되는 복귀 규칙 |
| 랭킹과 공지가 수작업이라 유실된다 | 자동 산정 랭킹과 공지 목록 |
| 66일이 끝나도 남는 게 없다 | 완주 배지와 **졸업 화면**, 다음 코호트 예약 |

개인 습관 트래커도, 채팅방도, 랭킹 경쟁 앱도 아닙니다. **같은 날 시작한 코호트의 소속감으로 완주율을 만드는 커뮤니티**입니다.

## 설계에서 신경 쓴 것

**66칸 진행판을 표시 전용으로 만든 이유** — 11열 × 6행이면 타일이 34px입니다. 44px 터치 기준에 못 미쳐서 클릭 대상으로 두지 않고, 날짜별 상세는 아래 목록에서 진입하게 했습니다.

**색상만으로 상태를 구분하지 않기** — 진행판 타일은 6가지 상태(완료 · 늦은 인증 · 면제권 · 미인증 · 오늘 · 미래)를 채움, 점, 사선, 테두리로 구분합니다. 배지도 아이콘과 라벨을 항상 함께 씁니다.

**대비를 계산해서 색을 정하기** — 대표 컬러 코랄 위에 흰 텍스트는 3.6:1로 기준 미달이라 검정(`#1A1A1A`, 4.8:1)을 씁니다. 코랄을 텍스트로 쓸 때는 어두운 변형(`#C63A1E`, 4.6:1)을 따로 둡니다.

**사진이 없으면 사진을 만들지 않기** — 텍스트만 남긴 "간단 인증"은 스토리 레일에서도 다른 이미지로 자리를 채우지 않고, 남긴 한 줄을 그대로 보여줍니다.

**정책을 규칙 문장으로 노출하지 않기** — "미인증 시 스트릭 리셋" 대신 "어제는 쉬었어요. 오늘 인증하면 다시 이어져요."로 씁니다.

## 배포

`main` 브랜치에 푸시하면 Vercel이 자동으로 배포합니다. 배포 루트는 `sixtysix/` 입니다.

## 실행

```bash
cd sixtysix
python3 -m http.server 8900
# http://localhost:8900
```

`file://` 로 열면 이미지 경로와 `localStorage` 가 동작하지 않습니다.

## 테스트

Playwright 회귀 테스트를 **360 · 390 · 430px** 세 폭에서 실행합니다.

```bash
cd qa
npm install && npx playwright install chromium
npm test
```

현재 등록 테스트는 210개입니다. 이번 점검에서는 목록만 확인했으며 전체 브라우저 회귀 테스트는 재실행하지 않았습니다.

핵심 흐름 9개(온보딩, 인증, 면제권, 복귀, 탐색, 응원·저장, 상태 전환, 졸업, 손상된 저장소 복구)와 12화면 구조·접근성, 스크린샷 회귀를 검사합니다. 자세한 항목은 [`qa/README.md`](qa/README.md).
