# 실제 인증·면제권·홈·기록 연결

## 개요

2026-10-05. 모집/참여 다음으로 본인 멤버십의 홈·66일 기록 조회와 인증/면제권 명령을 구현한다. 실제 경로는 `/activity/:membershipId`로 분리하고 기존 데모 화면은 유지한다. 계정의 현재/과거 참여에서 진입한다.

## 기준

- 사용자 → 코호트 → 멤버십 잠금, 잠금 후 DB 판정 시각 하나. 시작 최소 인원 판정은 모집 코드와 공유한다.
- 시작 전/취소/이탈/종료 쓰기 차단, 04:00 정상→늦은 경계, 16:00 정각 포함·1ms 후 종료, 마지막 66일차 늦은 접수 유지.
- 인증/면제권 같은 날 교차 중복 방지, 면제권 3회, 본문 JS trim 후 UTF-16 1~40, 허용된 샘플 사진만 저장.
- 동일 사용자 business 멱등 키를 모집 명령과 공유. 입력·경로 변경 시 충돌, 성공 재시도는 원래 응답. 인증 사실·성공 응답·감사를 함께 commit.
- TARGET_CHANGED에서 본문 보존 및 최신 일차/늦은 여부를 사용자가 다시 확인. 불확실한 실패는 원래 본문·키로 수동 재시도.
- 홈·기록은 서버 파생값을 표시. 사진 없는 인증 제공, 실제 사진 업로드는 범위 밖.
- 공개 범위는 저장하되 본인 조회만 구현. 타인 피드·순위·공개 범위 변경·운영/탈퇴는 후속.

## 검증 계획

실제 PostgreSQL에서 인증/면제권 경쟁, 마지막 면제권, 키 재시도/충돌/rollback, 시간 경계, 권한·취소·이탈, 비공개 본인 열람을 검증한다. UI 작성/면제 확인·만료/대상 변경·실패/재시도·66칸 조회와 모바일을 확인한다.

## 진행

구현 및 로컬 검증 완료 (2026-10-05). 원격 배포·실제 모집/회원 seed는 수행하지 않았다.

## 검증 결과

- Vitest **225개 / 22개 파일**, 프런트·서버 타입 검사, Vite 프로덕션 빌드 통과.
- 독립된 임시 PostgreSQL에서 DB/HTTP 통합 **68개** 통과. 인증·모집 기존 사례와 실제 활동 10개 사례를 포함한다. 운영/Preview DB는 사용하지 않았다.
- API 계약: OpenAPI 46개 경로와 입력 계약 14개 검증 통과. 활동 통합 테스트가 실제 Home·Record·WriteResult 응답도 스키마와 비교한다.
- Chromium 모바일 **360·390·430px × 14개 상태/흐름 = 42개** 통과. 작성·긴 본문 확인·비공개 기록·세션 만료·면제권 확인/저장·불확실한 실패/같은 요청 재시도·시작 전·종료·취소·이탈·마지막 늦은 접수·면제권 소진을 확인했다.
- 가로 넘침과 페이지 실행 오류 없음. 일반 조작 영역 44px 이상, 진행판 셀 24px 이상. 66칸 개수·방향키 이동·재시도 요청 본문/키 유지 확인. 360px 확인/기록/마지막 늦은 접수 스크린샷 시각 검수 완료.
- 모바일 검수는 테스트 API 응답 기반이다. 실제 공급자 로그인부터 원격 DB 저장까지의 통합 브라우저 검수, Vercel 배포 검증을 대체하지 않는다.

## 검수 중 수정

세션 만료나 접근 거부 후 새로고침이 실패하면 이전 비공개 기록이 화면에 남았고, 만료된 쓰기 후에는 초안이 남았다. 활동 조회의 401/403/404 응답에서 홈·기록·확인/재시도 명령·초안을 비우고 오류를 표시하도록 수정했다. 쓰기 중 401도 같은 정리를 수행한다. 자동 갱신에서도 만료를 안내한다.

회귀 테스트 5개를 먼저 추가해 수정 전 실패를 확인하고 수정 후 모두 통과시켰다. 단순 네트워크 실패 시 동일 요청으로 재시도하는 기존 동작은 유지한다.

## 재현

```sh
# 로컬 PostgreSQL의 임시 DB를 생성·삭제할 수 있는 테스트 계정 사용
cd sixtysix-v2
AUTH_TEST_DATABASE_URL=postgresql://LOCAL_TEST_USER@127.0.0.1:5432/postgres npm run test:auth-core
npm test
npm run build

# 별도 터미널에서 V2 개발 서버 실행 후 프로젝트 루트에서
node qa/scripts/activity-mobile.cjs
```

브라우저 스크립트는 `qa`의 Playwright 의존성을 사용한다. 기본 주소는 `http://127.0.0.1:5173`, 출력은 `qa/test-results/activity-mobile/`이며 `ACTIVITY_BASE_URL`·`ACTIVITY_QA_OUTPUT`으로 변경할 수 있다. 로컬 주소만 허용한다.
